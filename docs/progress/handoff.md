## 续接顺序

1. 优先完成独立人工评分、裁决与合法阶段推进；未签政策继续按保守边界处理，不把隔离夹具或送审结果当成正式通过。
2. 补受控的双口径对账和独立风险接收凭据，再验证结项送审；逐笔凭证核验、备注或布尔值不能代替正式证据。边界见 [ADR 0010](../adr/0010-review-submission.md)。
3. 继续补齐周报、事实与教训、八条规则和剩余契约；另行完成目标 Host、部署恢复及真实试点验收。

从 `dev/pmo-v1` 继续，先查 `git status --short --branch`、`git log -5`，阅读[输入核对](00-input-audit.md)、阻断清单和追踪矩阵。将每批测试证据记入对应阶段报告；不要为未实现操作注册假数据路由。根目录四份未跟踪的历史评审资料原样保留，不纳入提交。所有授权限于开发，禁止生产部署、代替签核或擅自推送。
