# PMO-Standalone-1.0.4｜最终审定开发输入包

## 结论和用途

这是对《PMO本体设计方案-Lite.html》及历史 V1.0.3 的第四轮全面核查后的**最终开发输入包**，用于交给 Codex 6.2 Astra 创建真实源码并持续实施。

- **允许直接开发**：M0～M4 中能够在授权本地/隔离测试环境独立完成的工程工作；必须逐阶段留下提交/测试证据。
- **外部阻断只影响正式批准**：八项待业务签核策略、真实客户试点、未接入 Host，可先用合成环境保守实现并标记 `BLOCKED_EXTERNAL`，不得伪造业务/上线通过。
- **仍不具备生产验收**：本包是规格、静态 Schema 与测试基线，不是运行中的项目管理系统。

## 开发启动顺序

1. 将本包所有文件放入仓库 `docs/spec/`，原始 HTML 另复制到 `docs/business-source/原始业务方案_PMOLite.html`；保留哈希不变。
2. 从当前授权仓库根目录启动 Codex 6.2 Astra，完整粘贴 `17_Codex_6.2_Astra_完整自主开发提示词.md`。
3. Codex 首先读 `AGENTS.md`，核对文件、仓库和业务缺口，运行三条静态检查，然后创建 ADR/ERD/真实迁移和 API/MCP 服务，分阶段持续实施。
