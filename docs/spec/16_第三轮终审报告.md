- `08_静态核验脚本.py`：102/102 参考向量执行通过；4 个故意错误的预期值被检查程序捕获；16 类、13 状态、3 关口、8 条规则和 4 Agent 模式引用齐全。

## 5. 开发建议和放行标准

**允许现在做：** M0 的脚手架、数据模型、开放接口、MCP adapter、静态契约映射和自动测试；M1 的登录、项目草稿、立项卡、需求/里程碑/预算/风险草稿等非争议部分。

**可以编码但暂不宣称正式业务可用：** 有争议默认值的评分聚合、P0 未确认红灯、条件结项与成本阈值判断等。可在合成数据/隔离环境中实现测试，签核后启用真实正式业务决策。

**禁止：** 直接上线/放开 Agent 自动审批、客户确认、凭证核验或归档权限；将静态 PASS 当作 Web/API/数据库/MCP 的真实功能验收；只依据 Codex 自述推进 M0～M4。

最终放行：**GO for M0 development; NOT YET PASS for M0 execution; NOT GO for production.**
