# 成本凭证的发生时间与冲销

候选输入的 `period` 在本实现中表示 UTC 自然月 `YYYY-MM`。金额或人天以正向凭证提交。候选状态不进入任何实际额；用于组织流水的 `posting_ledger` CostEntry 不构成获批预算。按月汇集的候选没有已证实的发生时刻，数据库必填时间以月初占位，Web/API 不将其作为实际发生时间展示。

核验 REST 的工程 DTO 在 `reason` 之外接收 `occurredAt`：正向凭证需要人工据原始来源提供带时区的真实时间，不能用录入时间或验证时间默认填充；须在所属 UTC 月且不超过核验时间。核验人须是可读项目的人工账号，具有独立的 `finance_verifier` 资格，且不同于凭证创建人或 Agent 委托人。此操作不对 MCP 暴露。冲销申请生成引用原凭证、金额取反、沿用原业务发生时间的 pending 行，由另一名有资格的人核验。验证时刻独立记载，所以按历史时点查询时，后核验的冲销不会回溯抵减原实际额。

业务来源指纹按项目、口径和规范化的凭证标识去重，不把金额或幂等键纳入身份。更正凭证应有可区分的更正来源编号。Q4 按首次已决定的立项通过时间严格比较发生时间，未通过时不隐藏已核验记录，正负流水均保留。不依赖当前阶段名称推断审批时间。
