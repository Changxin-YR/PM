# ADR 0020｜任务与报告读取契约

依据 V1.0.4 §6.1、§7.1、§8.4、§20.6 和工程 DTO §6–7。冻结规格、业务规则及接口和工具数量不变。

- `pmo_task_list` 和 `pmo_report_list` 的运行 MCP Schema 增加可选 `page`、`pageSize`，报告另允许 `reportType=daily|weekly`。默认仍为第 1 页、每页 20 条，上限 100。适配器原样传给已有 REST 查询，不单独读取数据库或改变权限。越过末页返回同一授权范围的 `total` 和空 `items`，不把超大页偏移交给数据库。
- 列表的排序和过滤均由 REST 服务在 SQL 中完成；先限真实项目、授权关联和资源范围，再计数、分页。`sourceRefs` 只包含返回页里的稳定资源版本。不同请求的 `asOf` 是各自查询时点。
