# 0002：项目范围不等于业务任命

自动加入 `allowed_project_ids` 仅代表同一令牌可在委托人本人的 drafting 项目操作草稿。角色变化不得扩大这种自动授权。0003 增加显式项目授权表；非本人草稿上必须同时满足：令牌项目范围、显式授权记录、委托人的有效成员身份、操作范围。仍需在具体服务核验 PM 等业务角色。已有范围没有来源证据时不推定为显式授权；需重新由人授权。此迁移不删除或覆盖旧数据。

规划资料编辑：依据主方案 §17.1/§17.2，drafting 的创建者或获任命 PM、designing 的获任命 PM 可维护未冻结资料；其余阶段拒绝草稿修改。第八个里程碑名额在锁住项目行后计算。已取消序号只作为历史保留，不影响活动名额。后续完成、计划变更、预测更新必须各走专用操作。
