# 0003：提名、发邀请、接受分离

依据：API 契约第 82 行、数据库成员约束、DEC-19（POLICY_PENDING）。基线有提名、本人收件箱和接受/拒绝，没有从提名发出邀请的人工操作。增加 `human_appointment_queue` 和 `human_issue_role_invitation` 两个工程接口，不充作 95 个基线操作，不暴露为 MCP 工具。

组织授权按人员、组织、项目角色、有效期和授权依据显式存储。不预置任何有权人员；管理员不是业务任命人。测试授权仅在随机测试 schema。正式授权来源及任命权范围须签核，本版本没有自助发放任命权入口。邀请有效期七天为隔离开发默认值，不是已签核政策。发邀请者不得兼任提名者或被提名人。仅在被提名人接受且授权仍有效时建立项目成员并同步项目指针。拒绝或到期不影响项目权限。不通过本流程取代在任角色。
