# 0011 独立对账、风险处置与生命周期审批

状态：技术实现；不代替 DEC-09/16/26 或真实业务签核。依据：主方案 §4、§5.3、§5.6、§20.5；规则基线结项布尔式；领域不变量 §2–3。

- 0018 追加只读对账回执与单独项目授权。两口径从已核验的私有来源 JSON 取得独立净额，服务校验实际字节、SHA-256、项目归属、截至范围和独立核对人；再与 verified 正负流水净额对照。保存初始/当前基线、预测、来源、输入及回执哈希，成本输入变化使旧回执失效。没有新增财务审批层级，也不自动清零。未完成承诺或未核验流水阻止结项。
- 风险处置回执与风险版本绑定。申请不是接受；指定接收人可认证后确认，或授权独立核验人凭明确列出身份、范围和接受条款的受控书面证据核验。非项目成员只能读自己的指定接收请求，不能读取风险台账。结项重新检查有效附件和处置回执。
- 0019 给非关口流转单独保存申请与裁决负载。不捏造 Review；项目阶段仍只由同一个服务写入。PM 完成凭证完备的交付流转；终止和暂停等由受权独立人决定；正常结项使用原 Review/Decision 服务。归档需 PM 申请、复盘四问、独立确认 Lesson 和独立人批准。未签核的合成终裁路径仅在明确隔离 schema 启用。
- 95 项基线以外的读取、核验与签署接口分别统计。恢复同一 PostgreSQL 快照及私有对象，不依赖旧备份证明新索引、附件类别或关联。
