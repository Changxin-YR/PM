# 0004：委托资格、密钥单次交付与重放

签发须人工会话、CSRF、明确的 delegator 资格、在有效期内的本人项目/操作权限。system_admin 仅获组织安全查看与撤销，不能替别人签发。初始账号默认不附带 delegator；仅在空库运行 bootstrap 时显式传 `--enable-delegation` 才额外赋予该资格。不迁移授予任何既有用户新资格。主动撤销本人凭据不需要仍保有签发权。

稳定回执在 JSON body，首个成功请求另以 `X-PMO-New-Token` 单次交付随机密钥。重试不含该头；如丢失原响应应撤销并重新签发。页面内存保存至关闭；不记入访问 URL、数据库、幂等缓存、审计或 Outbox。仅哈希用于鉴权。令牌短期上限 24 小时；一般幂等记录期限至少 90 天。组织级安全事件记录在专用追加表，不当作项目业务通知投递。

签发 If-Match 对应个人集合版本；撤销 If-Match 对应单个令牌版本。自动新增项目范围也提升两者版本。迁移不重签、复制或扩大旧令牌权限。每次鉴权重查有效期、撤销、账号/人员/组织状态；由本流程签发的令牌同时重查 delegator 资格。读范围与具体写操作还要服从当时的服务端权限。
