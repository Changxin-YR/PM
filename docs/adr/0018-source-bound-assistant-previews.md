# ADR 0018：带出处的模型预览

状态：工程决议，合成验证。依据：PMO-Standalone-1.0.4 §8.5–8.6、§20.3；不变更规则、审批权限或签核状态。

- 项目助理为同一个工作台。立项、结项、问答各有独立系统指令和封闭输出 Schema，工具清单为空；过程管家复用 [ADR 0013](0013-report-analysis-jobs.md) 的报告抽取 Schema 与异步作业，不加另一条候选写通道。切换不共享生成结果或对话历史。台账、评分、健康、关口预检和周报数字始终来自原确定性服务。
- 立项和结项对当前有权读取的片段分别选择核对视角；教训初稿必须基于实际填写的复盘回答。台账问答仅选择已授权、可追溯的既有答案；缺来源不外发、不补值。网关只接收最多 24 条、每条最多 600 字的片段和本次短编号，不发送资源引用、附件或账号 ID，也不发送筛选关键词。片段中的业务文字仍可能敏感，默认完全关闭外发。
- 模型输出仅含待核对的片段编号和固定视角。服务器重验模式、Schema、编号及视角资格并附原引用；模型不能提供数字、事实、自由文本结果、URL 或任意调用。单次最多 12 秒，格式或来源错误仅重试一次。失败提供明确人工降级，既有页面和原始材料保留。
- `POST` 要求项目范围、浏览器会话、CSRF、项目 revision 与幂等键。先保留同主体操作收据和脱敏的 `dispatch_authorized` 审计，提交后才调用网关。重试前及返回前重查身份、内容版本、可见性和来源哈希。更换材料或失权即拒绝；重校验不能收回之前已经授权发出的文字。
- 同一账号只允许一个处理中的预览；同键异参冲突；合法重放仅在原依据仍可读且一致时返回首次收据。35 秒后失联的预览可回读人工降级，不自动再次外发。真实业务表和 Outbox 不受影响；审计完成或降级与收据同事务，仅存哈希、来源和错误码，幂等回执仍是受控项目数据。分权数据库只能完成本操作 pending 收据，不得改写正式业务收据。

## 工程接口

`POST /api/v1/projects/{projectId}/assistant/suggestions`（`human_assistant_preview`）要求项目范围、人工浏览器会话及 CSRF、`If-Match`（项目 revision）、`Idempotency-Key`。请求为 `mode: charter`（可选 `keyword,category`）、`mode: closing` 或 `mode: ledger`（可选 `topic,keyword,category`）；过程管家仍使用报告分析。200 返回 `mode,status,basisHash,items` 和可选 `errorCode`，状态为 `ready/empty/manual`，条目只含服务端来源文字、引用、可选时点和固定建议。旧版本、在行请求、同键异参或过期来源分别受控拒绝；Agent 直调拒绝。不计入 95 项基线操作，不新增 MCP 工具，不写业务数据或推进流程。
