# 0021 工作台投影与健康时点

状态：开发采纳。依据主方案 §2 UI-01～03、§7；不改变规则版本、业务授权或冻结的 95 / 40 目录。

`GET /api/v1/project-overview` 仅限人工会话。与 `pmo_project_list` 共用项目 DataScope 和 `filters[stage]` / `filters[keyword]`。在一个 SQL 读取中先应用权限、筛选并分页，只为该页查找同组织已接受且未撤销的 PM 任命与最近持久健康采样。只有基本项目访问权的发起人不获得这些材料。`canEditDraft` 与原草稿写服务共用发起人和阶段条件，写服务仍独立锁定、校验权限和版本。

`healthSample` 有采样时点、规则版本、发布状态和快照引用；它是历史采样，不是当前灯色。查询不遍历项目重算健康，也不因读取写快照。旧格式和未来样本不进入此投影。Web 给列表读取得出的时间和快照时间不同标签；当前健康仍走确定性服务，数据不可信时不得补用过去灯色。MCP 不新增此工具，也不接收 Web 专用字段。
