# ADR 0015：无模型周报初稿及来源版本

来源：主方案 §5.6、§8.5–8.6、§20.3，DEC-22，原文条款 SRC-069、SRC-072、SRC-074；不改周报期限、三线业务阈值或 Fact 可信度规则。

现任 PM 选择 ISO 周，服务在项目事务锁内使用数据库时钟生成普通 `draft`，沿用编辑、实名提交和 PM 确认路径。周界为 Asia/Shanghai，已核验人天净额按发生时点落周，正负流水各计一次；候选、金额、口头申报不进入该净额。没有核验流水、净额为负或超出可申报数值范围时，不替 PM 填申报值。

里程碑预测、需求、风险与三线使用生成时点的现有项目服务，不把当前状态冒充所选周周末历史状态。完工仅使用有验收回执和可复核原件的里程碑；生成时三线不可信则不附旧灯色。Fact 摘要仅采同周已核验的高/中可信来源，有冲突、来源无效或客观证据失效的条目不展示。Fact 原话、版本和证据留在人工专用依据中，不作为新增流水或用于替代里程碑完工。为控制单页规模，详情标示未展示项数量。

迁移 `0027` 新增不可改写的 `reports.weekly_basis`，含时点、规则、来源 hash/引用及生成时数据摘要。旧手工报告仍使用原 hash 公式；新报告 hash 绑定生成依据和 PM 编辑内容。提交与发布前重算相关台账、有效需求、风险和可信 Fact 指纹；与原稿不同则拒绝，保留旧稿并允许生成新版本。不将单纯时间流逝、该周报本身的提交回执或无关任务视为材料变动，历史依据仍标生成时点。拒绝丢弃已持久化依据的降级。发布只改变报告自己的确认版本和审计，不修改基线、成本入账或 Fact 可信度。MCP 仍走原报告服务，封闭输出不新增人工专用字段。
