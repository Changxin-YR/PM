# ADR 0008：交付、内部验收与客户确认

仅开放执行或交付中的项目，且必须匹配共同签署的初始基线快照。该需求的未决范围变更冻结状态；未来新版本须通过正式变更流程接入，不能把版本数字直接当成批准。当前 PM 可交付，显式委托给 Agent 时在签发和使用时均核对 PM 身份；内部验收只接受当前 PM 或 reviewer 的会话。客户须有有效项目任命及同项目客户联系人关联，不能是本条需求交付/内部验收的执行人。每一步锁定项目，重验该需求对应的已核验文件，与状态更新一起写入不可变回执、审计和幂等记录。

客户确认策略未签核。普通预览不提供正式确认；只有显式指定且匹配当前随机测试 schema 的隔离服务能演练成功路径。此例外不是生产配置或正式授权；无用户可通过 HTTP 或 MCP 请求开启它。
