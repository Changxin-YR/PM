# 0023 类别预算、预测与历史成本

项目金额和人天合计继续由 `cost_plan_versions` 和获批 `cost_entries` 提供。类别预算版本保存完整分配及其来源。类别间调拨仍走预算变更审批。同额调拨只新增分配版本，金额变更同时切换受影响的合计基线和类别版本。项目锁串行化提报、审批、冻结、预测与分类。原流水外键及初始基线保留。

类别剩余预测单独编号，记录业务时点、服务端生效时间、预算和已知实际基础。汇总由同一个事务写入原计划版本。新实际、分类或预算变化后，仍显示原预测及其待复核状态。系统不根据发生额扣减预测。

类别预算草稿由七类完整分配组成。组织在明确环境激活 DEC-26 类别政策后，切换时点之后创建的项目从类别预算开始。项目级激活也约束尚未获批总额的指定项目。已采用类别计划的项目在落地冻结时须提交完整预测和有效政策。政策撤销后仍保留采用范围，待有效替代政策生效后重新送审。已有获批总额的项目可通过独立预算审批完成首次等额分配。

历史未分类流水保持原值和原类型，使用提报和独立核验的追加记录归类。冲正随原流水归类。历史查询采用查询时点已知的发生、核验与分类记录，归档资料保持只读。

原金额和人天对账证明其签核的合计基础。类别调拨及流水只改类别时，不使该历史证明失效。类别对账同时校验类别分配、预测和实际依据，分类版本变更后按新依据重签。结项可以使用仍有效的适用对账证明。类别预算和预测不改变健康计算阈值或增加类别超支硬门槛。
