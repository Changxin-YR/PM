## 可以直接试的四段对话

四个模式共用一个项目入口。可以回到上一种模式继续聊天，查看一条回答的来源和读取时间，或回到对应业务页面。对话按项目和模式分别保留在当前页面会话中，每种模式保留最近 40 轮，刷新页面或退出账号会清空。权限、评分、预算和归档结果均取自业务系统。[设计方案第 8.5 节](../../spec/01_PMO_V1_独立系统完整开发方案.md#85-内置单-agent-四模式必须与原文一致)

| 模式 | 可直接输入的问题 | 本例的实际回答或动作 |
|---|---|---|
| 立项评审 | 立项评分有哪些弱项？再问“依据呢？” | 显示正式总分 4.00，本次评分未列弱项。可展开原评审和裁决编号，查看立项材料，下载评审材料。 |
| 过程管家 | 帮我起草本周周报 | 从里程碑、客户确认、风险和已核验工时整理草稿。第二期显示 40 人天。可继续问待澄清事实，或打开项目报告。 |
| 结项回顾 | 先问“这个项目结项还差什么？”，再说“带我做一次复盘四问” | 前者说明项目已归档。后者依次询问目标差异、过程、可复用做法、教训。答完汇成四项草稿。在可编辑复盘阶段，项目经理可把草稿带入正式表单，核对后保存。归档项目可打开既有复盘记录。 |
| 台账问答 | 预算和实际投入相差多少？ | 对照已核验流水，金额少用 2,000 元、人天少用 2 人天。可继续问“展开第1条”“这些数据是什么时候的？”“再查一次”，或打开成本台账。 |

本例还查询了预测延期、立项前支出、需求变更历史、已确认教训及当周黄红灯。周内早先的成本红灯与最近的绿灯分别显示。查不到“天文台望远镜”相关教训时，回答会说明缺少可核验来源。指定无法唯一定位的“西湖冷库”时，界面提示核对项目编号。审批和归档保留在有权限的人工入口。[逐轮问答与实测数据](../../../.local/r6-evidence/park-browser/实测.json) · [桌面截图](../../../.local/r6-evidence/park-browser/过程管家对话.png) · [窄屏截图](../../../.local/r6-evidence/park-browser/窄屏对话.png)

## 项目怎样走到归档

| 环节 | 经办人与业务结果 |
|---|---|
| 开户、任命、立项 | 杜衡发起，陶然任项目经理，陆遥任项目发起人。杨柳、谭峰用独立身份评审。项目通过立项关口，立项卡记录了派工、回传和签收的验收目标。 |
| 计划与基线 | 三条需求分别对应接单、回传处理结果、查看签收记录。设工单流程评审、现场联调及回传、客户签收与移交三个里程碑。陶然与客户代表宋兰双签需求基线。 |
| 落地评审与变更 | 落地评审有条件通过，生成“三张离线回单”抽查任务。物业调整检修窗口后，陶然发起现场联调顺延一天的变更，陆遥独立审批。 |
| 执行与报告 | 留存三份日报、两份正式周报。钱雅按研发、实施、管理三类独立核对签到与工作量，分别核验两期的 38 和 40 人天。两份周报分别取得隔离收件回执。 |
| 事实、证据与风险 | 同一班次的两份日报分别记作两张和三张待补传回单。系统标记冲突，复核原始签收清册后确认三张。完成抽查任务并核验里程碑和需求原件。项目经理自行关闭风险时，系统按角色拒绝，由独立评审人完成关闭。 |
| 客户验收与对账 | 三条需求均经客户确认。任川以单独的对账身份核对金额和人天，绑定独立核验过的对账附件。七类剩余投入均归零。 |
| 结项、复盘与归档 | 通过结项关口，对照签收原件完成四维评分反校，登记复盘四问。独立评审人确认“把离线回单的本地留存、重传和签收做成逐单清单”的教训，批准归档。 |

## 本机复现

从仓库根目录运行。页面服务使用 `18790`，接口使用 `18791`，案例库使用 `55456`。同一组织的“企业移动工单管理系统”仍可单独查阅实施阶段。

```powershell
$env:PMO_PILOT_RUNTIME = 'native'
$env:PMO_PILOT_INSTANCE = 'r6-preview'
.\.venv\Scripts\python.exe -m scripts.pilot_local status
.\.venv\Scripts\python.exe -m scripts.pilot_r6_case
node web/e2e/r6-park.mjs
```

项目经理账号为 `r6-m-pm`。需要重新登录时，可在本机终端沿用上面的环境，执行 `.\.venv\Scripts\python.exe -m scripts.pilot_r6 login m-pm` 查看该演示账号的登录资料。原始证据、浏览器截图与打印件位于当前机器的 `.local/r6-evidence`。版本库保存案例及验证脚本。[案例流程](../../../scripts/pilot_r6_case.py) · [冲突与收件](../../../scripts/pilot_r6_case_receipts.py)
