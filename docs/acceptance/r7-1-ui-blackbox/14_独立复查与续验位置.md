## 续验交接

1. 由组织业务策略责任人核实两个项目是否有合法生效的立项裁决依据。普通项目从 3.75 分评审工作台续办。快速项目从 4.20 分工作台按适用规则续办。页面只有待签提示时保留现场。
2. 核实客户项目绑定、财务分类核验和独立对账的授权主体。独立登记、签核以及真实收件均保留原责任边界。维护文档中的专用终端未用于业务验收。
3. 项目一已有 12 需求、5 里程碑与两版周报。继续时先依次核对补强任务、客户签署基线、正式预算、执行及双口径流水。翻印变体的数据留在该变体。项目二的历史教训验收要等待项目一正式确认教训。
4. 已生成可复验的前端候选，原工作台运行 R6。09 号文档按独立候选版本保留首个失败与其后成功的各自证据。08 号表给出每项缺陷的根因、最低修复要求和剩余条件。
