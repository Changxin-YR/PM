## 模型条件补测

模型补测使用隔离工作台 18793 和隔离 API 18794。请求地址为 https://tokease.cn/v1/chat/completions，协议为 chat_completions_json，模型标识为 deepseek-v4.1-flash-1017。密钥只从环境变量读取，没有写入仓库、证据或报告。模型范围限定到项目一及其已下载的 2026-W48 v2 报告来源。

立项评审助理页面生成了两条待人工核对的来源摘录，引用客户吸引力和预期收益。台账问答的事实整理在模型未选出可用条目时回退为台账原文。周报分析连续两次在页面显示“分析超时 · 已关联人工任务”，经理能从“我的补强待办”进入对应的“报告人工复核”任务。模型真实分析因此记为条件受阻，没有计入模型通过。
